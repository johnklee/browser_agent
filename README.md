# browser_agent

`browser_agent` is a Python-based agent designed to automate browser interactions, scrape web data, and extract structured content from online sources.

- `browser_agent/`
  - Main Python package of the project.
  - Can be installed as a reusable package using:
    ```bash
    pip install browser-agent
    ```
  - Contains the core implementation of the browser agent system.

- `browser_agent/agent/`
  - Holds the implementation of AI agents and orchestration logic.
  - Responsible for handling user requests and coordinating browser tools.

- `browser_agent/config/`
  - Stores configuration-related modules and settings.

- `browser_agent/tools/`
  - Provides reusable tools and browser automation integrations (e.g., Playwright, BeautifulSoup scrapers).

- `browser_agent/utils/`
  - Utility/helper functions shared across the project.

- `lab/`
  - Used for experimental code, prototypes, and research scripts.
  - Example:
    - `parse_amazon_top_n.py` — script to scrape Amazon Hot New Releases.

- `tests/`
  - Contains unit tests and integration tests.

- `pyproject.toml`
  - Python project configuration file defining dependencies, build system, and tooling.

- `uv.lock`
  - Dependency lock file generated by `uv`.

- `requirements.txt` / `requirements_test.txt`
  - Compiled requirements files generated by `uv pip compile`.

- `README.md`
  - Main project overview and onboarding document.

- `LICENSE`
  - Software license.

# Features

- Browser automation & web crawling using Playwright and BeautifulSoup.
- Agent-based task execution and data extraction via Google ADK.
- Reproducible package and dependency management powered by `uv`.

# Usages

The `browser_agent` package exposes a Google Agent Development Kit (ADK) `root_agent` that can be launched using the `adk` CLI:

## 1. Interactive CLI (`adk run`)

```bash
adk run browser_agent/agent
```

## 2. Web Interface (`adk web`)

```bash
adk web browser_agent
```

## 3. REST API Server (`adk api_server`)

```bash
adk api_server browser_agent --port 8888
```
